# RM 哨兵机器人阶段规划

## 总路线

```text
底盘稳定
→ 底盘补测与通信
→ 二维云台
→ 视觉追踪
→ 发射机构
→ 完整通信与安全
→ 激光雷达导航
→ 整机任务整合
```

## 阶段 0：总体设计冻结（完成）

```text
确定 STM32 / 树莓派职责
确定四电机、编码器、IMU、OLED 引脚
确定阶段计划、安全底线和 AI 分工
```

## 阶段 1：四轮独立速度 PID（完成）

```text
四轮独立 PWM 和方向
四组编码器
四轮独立 PID
目标 RPM 跟踪
输出和积分限幅
上电默认停车
```

验收基线：

```text
1 ms PID
KP=0.4 / KI=2.5 / KD=0
200 RPM 阶段验收上限
硬件极速约 330 RPM
```

## 阶段 2：底盘运动学、里程计与 IMU（完成）

```text
skid-steer：vx + omega
四轮目标 RPM 解算
整车 x / y / yaw 里程计
IMU yaw 标定与融合
直行航向闭环
定点转向
轮径、等效轮距、wheelScale 标定
```

验收结果：

```text
直行 2 m 纵向误差 0.1%
横向跑偏 ≤5 cm
定点转向误差约 -0.7°
IMU 融合 yaw 正常
掉线 SAFE STOP
```

## 阶段 3：底盘补测与基础通信（进行中）

```text
弧线旋转测试
单轮 1 m 精度测试
原地 360° 测试
闭环回起点测试
编码器/IMU 模式切换对比
基础双向 UART
定长帧、序号、校验
CMD_VEL / CMD_STOP / TELEMETRY
200 ms 通信超时停车
```

## 阶段 4：二维云台

```text
Yaw / Pitch 控制
角度限位
角度闭环
安全位置
与底盘坐标系关联
```

## 阶段 5：视觉目标追踪

```text
摄像头采集
目标检测
目标识别
云台视觉伺服
目标丢失保护
```

## 阶段 6：发射机构与完整通信安全

```text
发射准备和状态
允许/禁止发射
发射互锁
变长帧 / CRC16
完整心跳
重连
独立急停通道
完整安全状态机
```

## 阶段 7：激光雷达和自主导航

```text
雷达采集
SLAM
定位
避障
路径规划
自主移动
```

室外全局定位需求出现后，再加入：

```text
GPS / RTK
GPS + IMU + 里程计 + 雷达融合
```

## 阶段 8：整机任务整合

```text
自主导航
目标发现
云台瞄准
发射判断
任务状态机
人工接管
故障恢复
```

## 每阶段统一要求

```text
代码完成
Keil 编译通过
实车测试通过
测试数据记录完整
安全能力不回退
阶段验收后才进入下一阶段
```
