# RM Sentry 四驱底盘车端闭环动作与可视化上位机（S3-DEMO v3 增强版）

本目录为阶段 3 收尾展示层可视化上位机（`TOOL/hmi/`），配合 STM32 端 `comm_actions.h/c` 实现**车端闭环参数化动作 (`TYPE 0x05 CMD_ACTION`)**、**直行梯形加减速**、**`0x06` 远程里程计归零**、**`WASD` 五档八向赛车操控**、**双击地图演示级指点导航**、**花式动作剧本编排器**、**单一司机两层仲裁**与**原始帧调试工具**。

> **零侵入保证**：本目录通过 `protocol_ext.py` 扩展 `TYPE 0x05`，**未修改**上级目录的 `TOOL/protocol.py` 与 `TOOL/comm_tool.py`。

## 1. 环境与依赖

```bash
pip install -r requirements.txt
```
（已验证 `PySide6 6.11.1` + `pyqtgraph 0.14.0` + `pyserial 3.5`）

## 2. 启动方法

- **方法 A（推荐，双击一键启动）**：
  直接双击本目录下的 **`run_hmi.bat`**。
- **方法 B（命令行启动实车串口）**：
  ```bash
  cd D:\stm32\stm32f4\breath\TOOL\hmi
  python main.py --port COM6
  ```
- **方法 C（离线仿真模式 Mock）**：
  ```bash
  python main.py --mock
  ```

## 3. S3-DEMO v3 五大增强与界面说明

1. **一、顶栏**：串口选择、波特率 `9600 8N1`、连接状态指示、`仿真车端(Mock)` 开关，以及右侧醒目红色 **「🛑 紧急停车 E-STOP (Space)」** 按钮（按键盘**空格键**可随时一键触发 `CMD_STOP` 急停并清空所有队列）。
2. **二、参数化动作区 (`TYPE 0x05 CMD_ACTION`)**：
   - **W1 `0x01` 梯形加减速直行** (`mm` 可自由填写，起步 `250 ms` 从 `0.08 → 0.25 m/s` 爬升，尾段 `150 mm` 线性降速至 `0.07 m/s` 蠕行刹停，`<400 mm` 短距离自动降峰至 `0.14 m/s`)；
   - **`0x02` 定点转向** (`°` 可自由填写，车端按 `0.1°` 复用 `mode 2` 转向到位自动刹停)；
   - **`0x04` 掉头 `180°`**、**`0x03` 动作停车**（`0x05` 保持回起点预留不动）；
   - **W2 `0x06` 远程里程计归零**（发送 `AA 55 05 SEQ 06 00 00 CRC8 0D 0A`，车端强制停车并调用 `Chassis_ResetOdometry()` 清零 `X/Y/OdomYaw`、重锁存 `IMU` 航向零点，同时清空轨迹图）。
3. **W3 `WASD` 键盘赛车模式**：
   - 勾选 **「开启 WASD 键盘驾驶」** 后，按住 `W/S` 前进/后退、`A/D` 原地左转/右转、`W+A / W+D / S+A / S+D` 八向差速弧线转向，**松开按键自动下发 `CMD_VEL(0, 0)` 平滑停稳**；
   - 支持 **五档变速**，开启 WASD 后可按数字键 **`1~5`** 直接换挡：

     | 档位 | 线速度 vx | 原地角速度 ω | 说明 |
     | :--- | :--- | :--- | :--- |
     | 1 慢速 | `0.15 m/s` | `0.80 rad/s` | 精细微调 |
     | 2 常速 | `0.30 m/s` | `1.20 rad/s` | 标准巡航（默认） |
     | 3 快速 | `0.60 m/s` | `1.80 rad/s` | 运动竞速 |
     | 4 狂飙 | `0.75 m/s` | `2.40 rad/s` | 高速竞技 |
     | 5 极速 | `0.85 m/s` | `3.00 rad/s` | 贴近车端硬限幅 `CHASSIS_MAX_VX_MPS = 0.869 m/s` / 单轮 `250 RPM` |

     > 4/5 档弧线行驶时，若某轮超过 `250 RPM`，车端会按比例等比缩放四轮转速（保持轨迹形状、不会失控）。高速档请在空旷场地使用，随时可按空格急停。
   - 开启或按下 `WASD` 自动清空剧本队列并触发车端单一司机 `Abort`。
4. **W4 车头朝向射线 & 双击地图「演示级导航」**：
   - 左上 **X-Y 平面轨迹图** 实时绘制车体坐标与金色**车头朝向射线 (`ImuYaw`)**；
   - **双击地图任意目标点 `(X*, Y*)`**：自动解算 `Δyaw` 与直线距离 `L`，串行下发 `CMD_ACTION(0x02, Δyaw)` → 等待 `DONE` 停稳 `0.3s` → `CMD_ACTION(0x01, L)`，到达后自动在日志区输出**演示级导航落点误差 (`~5 cm` 量级)**。
5. **W5 动作剧本编排器**：
   - 内置 **`[🟩 正方形巡逻]`**、**`[🟦 2m 折返跑]`**、**`[🟧 左右摇摆舞]`** 三大一键花式剧本，并支持自定义增删步骤；
   - **两层打断机制**：任何 `WASD` 按键、手动动作按钮、`CMD_VEL` 或空格急停，均同时**清空上位机待发队列**并触发**车端 `Comm_Action_Abort()`**。
6. **「🛠 原始帧工具」标签页**：
   - 手填 `TYPE / SEQ / DATA` 十六进制组帧预览与发送，新增 **`里程计归零 (05 06 00 00)`** 快捷按钮，支持 `HEX / ASCII` 对照与 26B `TELEMETRY` 拆解。
