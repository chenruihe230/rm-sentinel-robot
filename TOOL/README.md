# HC-12 无线串口上位机调试工具（S3-03）

本目录为电脑端 Python 半双工调试与遥测工具，严格对应 STM32 端 S3-01 / S3-02 通信协议（帧格式 `AA 55 | TYPE | SEQ | DATA | CRC8 | 0D 0A`，多字节小端）。

## 1. 运行环境

- Python 3（已验证 Python 3.14）
- 依赖库：`pyserial`（若未安装可执行 `pip install pyserial`）

## 2. 硬件接线与 HC-12 参数

- **电脑端（HC-12 A）**：插在 USB-TTL 上连接电脑 USB 口（`SET` 悬空退出 AT，USB-TTL 建议接 `5V` 供电）。
- **小车端（HC-12 B）**：`TXD → PA10`、`RXD → PA9`、`GND` 共地、`VCC → 独立 3.3V`（禁止从 STM32 核心板直接取电）、`SET` 悬空。
- **模块配置参数（已按 S3-01B 配对并掉电保存）**：
  - 波特率：`9600` (`8N1`，无流控)
  - 信道：**`CH002`**（避开默认 `CH001`）
  - 串口模式：`FU3`
  - 发射功率：`P8 (+20 dBm)`

## 3. 自检与运行命令

1. 单独运行协议与 CRC8 自检：
   ```bash
   python protocol.py
   ```
2. 启动上位机连接小车（默认 `COM3`，若端口不同可用 `--port` 指定）：
   ```bash
   python comm_tool.py --port COM3
   ```

## 4. 交互指令示例

| 输入指令 | 含义 | 说明 |
| :--- | :--- | :--- |
| `v 0.2 0` | 发送速度指令 | 以 `vx = 0.20 m/s, omega = 0.0 rad/s` 行驶并持续心跳维持 |
| `v 0 1.0` | 原地旋转 | `vx = 0, omega = 1.0 rad/s` |
| `s` | **紧急停车** | 立即发送 `CMD_STOP`（执行 `Chassis_ForceStop`）并切回 `POLL` |
| `m 1` / `m 0` | 切换航向融合 | `1 = IMU 为主融合`，`0 = 纯编码器积分`（不改 `headingMode`） |
| `p` | 纯轮询 | 只发送 `CMD_POLL` 读取 26B 遥测 |
| `t` | 断连超时自测 | 暂停发送 `0.8 s`，验证 STM32 超过 `400 ms` 自动停车且 `timeout_count +1` |
| `q` | 安全退出 | 先发 `CMD_STOP` 停车后再关闭串口退出 |

## 5. 半双工时序与安全提示

- **半双工防撞车**：工具每周期仅发送 1 帧并等待 STM32 回传 33 字节 `TELEMETRY`（或 `260 ms` 读超时）后再发下一帧，绝不连续猛发撞包；在 HC-12 `9600 bps` 实测往返延迟（`170~180 ms`）下，实际稳态轮询频率约为 **`5.6~5.8 Hz`**。
- **400 ms 断连保护**：STM32 收到有效帧后若超过 `400 ms` 未收到下一帧，会自动触发 `Chassis_ForceStop()` 停车并累加 `timeout_count`。
- **`CMD_STOP` 优先**：重复序号下 `CMD_STOP` 仍强制执行；实车测试前请确认周围空旷或先架空，先输入 `s` 确认四轮 `RPM=0` 后再下发 `v` 指令。
