## 0. 本单性质

```text
执行人：人类用户（亲手接线、进 AT 模式配参数）
反重力：只出分步指南 + 每步确认方法，不得声称自己改了什么
工程文件：本单零改动（不改 .ioc / 源码 / hex）
目标：两块 HC-12 配成 同频道 + 同 9600 8N1 + 同功率 + 同工作模式，并验证掉电保存
```

**顺序红线**：必须先配好两块模块、AT 查询确认、断电重启再确认，**最后才把 HC-12 B 接到 STM32**。禁止先接 STM32 再边通信边猜参数。

## 1. 硬件清单

```text
HC-12 A（电脑侧）  ← USB-TTL → 电脑
HC-12 B（底盘侧）  ← USB-TTL → 电脑（先用同一个 USB-TTL 分别配，配好再接到 STM32）
天线：两块都装 433 MHz 天线（不装天线严禁上电发射，会烧模块）
供电：HC-12 发射峰值 ~100 mA，禁止从 STM32 的 3.3V 取电；用 USB-TTL 的 5V 或独立电源均可配置阶段使用
```

## 2. 引脚与 AT 模式（手册已查证）

```text
HC-12 引脚：VCC / GND / TXD / RXD / SET

进 AT 配置模式：
  方式一：正常工作时把 SET 拉低 → 进入 AT
  方式二：SET 先拉低再上电（固定以 9600 N,1 进 AT，推荐）
退出 AT：SET 释放（高电平/悬空）
正常工作：SET 必须为高电平或悬空，绝不能拉低
```

**注意**：进 AT 时若用方式二，串口固定 9600 8N1；配完改了波特率后，退出 AT 用新波特率通信。

## 3. 要配置的 AT 指令（两块都做，参数完全一致）

| 指令 | 作用 | 本工程取值 |
|---|---|---|
| `AT` | 测试，应返回 `OK` | — |
| `AT+B9600` | 串口波特率 | **9600**（默认，确认即可） |
| `AT+C001` | 频道 | **CH001**（433.4 MHz，默认，确认即可） |
| `AT+FU3` | 工作模式 | **FU3 全速**（默认，确认即可） |
| `AT+P8` | 发射功率 | **8（20 dBm/100 mW）** 或按现场调整，两块必须一致 |
| `AT+RX` | 查询当前参数 | 逐项核对上面四项 |

**串口格式**：9600 8N1，无流控（与 S3-01 协议规划一致）。

> 因为出厂默认就是 FU3 / 9600 / CH001 / P8，多数参数只需 `AT+RX` 确认即可，不必逐条写。若现场干扰大需换频道（如 `AT+C021`），**两块必须同步改**。

## 4. 分步操作指南（反重力按此格式出给用户）

要求每一步写清「点哪里 / 发什么 / 期望返回 / 怎么确认」，至少覆盖：

1. **装天线** —— 强调不装天线禁止上电；
2. **HC-12 A 进 AT**：SET 拉低 → 上电；USB-TTL 打开串口助手（9600 8N1）；
3. **发 `AT`** → 期望 `OK`（不通就查 TX/RX 交叉接线、共地、SET 是否真低）；
4. **发 `AT+RX`** → 记录返回值，核对 FU3/9600/CH001/P8；
5. **如需改**（功率/频道）逐条发 `AT+P8` / `AT+C001` 等，每条确认返回 `OK+...`；
6. **退出 AT**：SET 拉高/悬空，断电重启；
7. **再进 AT 发 `AT+RX`** → **确认掉电后参数仍保存**（这是关键步骤，不能省）；
8. **HC-12 B 重复 2~7**，两块参数逐项比对必须一致；
9. **联调前检查**：两块同频道、同步特率、同功率、同 FU3，天线都在，SET 都释放；
10. **最后才接硬件**：HC-12 B 的 TXD→STM32 PA10(RX)、RXD→STM32 PA9(TX)、GND 共地、VCC 独立 3.3V；HC-12 A 留在 USB-TTL 接电脑。

## 5. 接线表（配好后，给 S3-02 用）

```text
HC-12 B（底盘侧）        STM32F407
  TXD        ────→       PA10 (USART1_RX)
  RXD        ←────       PA9  (USART1_TX)
  GND        ────        共地（必须与 STM32 共地）
  VCC        ────        独立 3.3V（禁止从 STM32 3.3V 取电）
  SET        ────        高电平/悬空（正常工作）

HC-12 A（电脑侧）        USB-TTL
  TXD/RXD  交叉接 USB-TTL 的 RXD/TXD
  GND       共地
  VCC       USB-TTL 5V 或独立电源（配好后可保持在 3.3V 也可）
  天线      433 MHz 天线必须装
```

> ⚠️ 电平：推荐 HC-12 B 用 3.3V 供电，TXD 即 3.3V 电平直连 STM32，最安全。若用 5V 供电，TXD 是 5V 电平，需确认 STM32 PA10 的 5V 容忍性或加电平转换 —— 不确定就用 3.3V。

## 6. 完成标准 / 回传

```text
1. 两块 HC-12 均 AT+RX 查询参数一致（FU3 / 9600 / CH001 / P8 或现场统一值）
2. 断电重启后 AT+RX 复查，参数保持（掉电保存验证）
3. SET 均处于释放状态
4. 天线均已安装
5. 工程文件零改动（.ioc / 源码 / hex 未变）
6. 给出最终接线确认表（谁接 PA9 / PA10 / 共地 / 独立电源）
```

**回传**：分步指南 + 两块模块 AT+RX 查询结果 + 掉电保存验证结果 + 最终接线表 + 任何异常（如某模块 AT 无响应）。
