## 2. 总体架构

```text
摄像头 / 激光雷达 / GPS（远期）
              ↓
Raspberry Pi 5
  视觉检测、追踪、SLAM、导航、任务决策
              ↓
UART / USB / CAN
              ↓
STM32F407
  四轮 PID、底盘运动学、IMU、云台、发射、安全
              ↓
电机 / 编码器 / IMU / 发射机构
```

职责边界：

- 树莓派负责感知和任务决策。
- STM32 负责实时控制和安全。
- 树莓派发送 `vx / omega` 等高层目标，不直接操作电机 PWM。
- 无线透传用于调试、遥测和人工接管，不进入 1 ms PID 控制链路。
- 底盘是普通轮子四轮独立驱动差速底盘（skid-steer），无独立侧移。

## 3. 当前硬件与标定映射

### 3.1 电机和编码器

| 电机 | PWM | IN1 | IN2 | 编码器 | 轮位 |
|---|---|---|---|---|---|
| M1 | PE9 / TIM1_CH1 | PE0 | PE1 | TIM3 / PA6 / PA7 | 左前 |
| M2 | PE11 / TIM1_CH2 | PE2 | PE3 | TIM4 / PD12 / PD13 | 右前 |
| M3 | PE13 / TIM1_CH3 | PE4 | PE5 | TIM5 / PA0 / PA1 | 左后 |
| M4 | PE14 / TIM1_CH4 | PE6 | PE7 | TIM2 / PA5 / PB3 | 右后 |

方向逻辑：

```text
IN1=1, IN2=0 → 正转
IN1=0, IN2=1 → 反转
IN1=0, IN2=0 → 停止
IN1=1, IN2=1 → 刹车
```

### 3.2 其他资源

```text
PB6 / PB7：I2C1 OLED，100 kHz
PB10 / PB11：I2C2 IMU，400 kHz
IMU：维特 10 轴裸机模块，地址 0x50，6 轴模式
PA13 / PA14：SWD
PH0 / PH1：HSE 引脚
M4_IN2 = PE7
```

### 3.3 底盘标定基线

```text
轮径 WHEEL_DIAMETER_M = 0.066404f
编码器分辨率 = 1320 计数/圈
等效轮距 chassisTrackWidthM = 0.3703f
几何轮距约 0.20 m
motorGain[] = {1.0, 1.0, 1.0, 1.0}
wheelScale[] = {1.015, 1.015, 1.015, 1.015}
```

skid-steer 原地旋转存在侧滑，运动学和里程计必须使用等效轮距 `0.3703f`，不能直接使用几何轮距 `0.20 m`。

## 4. 系统时序与控制基线

```text
底盘 PID / 编码器采样：1 ms
速度低通：LPF 0.20
零计数保护：20 ms
IMU 采样：约 100 Hz
云台 PID：1～5 ms
安全状态检查：1～10 ms
状态遥测：20～50 Hz
OLED 刷新 / 诊断窗口：100 ms（不参与 PID）
```

```text
PID：KP=0.4 / KI=2.5 / KD=0
PID 输出：-100～+100
目标轮速：±250 RPM
硬件极速：约 330 RPM
坐标系：+X 前 / +Y 左 / +Z 逆时针
上电默认停车
```

1 ms PID 已落地，100 ms 只用于诊断显示，不替代实时控制。

### 5.1 阶段 1：四轮独立速度 PID（完成）

```text
四轮独立 PID

```

### 5.2 阶段 2：底盘运动学、里程计与 IMU（完成）

六项能力：

```text
S2-01 接口和架构
S2-02 差速底盘运动学
S2-03 整车里程计
S2-04 IMU 标定与 yaw 融合
S2-05 轮径、轮距、motorGain / wheelScale 标定
S2-06 + S2-06B 航向闭环与精度微调
```

核心实测：

```text
直行 2 m 纵向误差：0.1%
直行 2 m 横向跑偏：≤5 cm
定点转向误差：约 -0.7°
IMU 融合 yaw：正常
通信/指令掉线：SAFE STOP
最终基线 hex：2026-11-21 16:20:31
编译：0 Error / 0 Warning
```

### 5.3 五条工程结论

1. skid-steer 几何轮距不等于等效轮距：几何约 `0.20 m`，实测等效 `0.3703 m`。
2. 闭环 PI 已将四轮差拉到约 ±0.5%，`motorGain[]` 保持全 `1.0`，不要加入无效开环补偿。
3. `wheelScale=1.015` 只修正里程读数，不修正实际轨迹；横偏必须靠航向闭环解决。
4. 定点转向需要低速保底、过冲反向和容差带刹车等待，不能只放宽角度容差。
5. OLED 阻塞 I2C 约 90 ms，IMU 必须独立使用 I2C2，不能与 OLED 共用 I2C1。

## 8. 协作规则

1. 同一个文件同一时间只能有一个模型修改。
2. 免费工具优先完成调研、文档、测试和初审。
3. 付费模型只做关键架构、疑难排错和阶段验收。
4. 每个开发任务必须限定修改文件范围。
5. CubeMX、定时器、引脚和安全逻辑不得由实现模型随意修改。
6. 每个阶段完成后必须编译、测试、记录，再进入下一阶段。
7. 实车测试结果由人类确认，不以模型推测替代硬件结果。
