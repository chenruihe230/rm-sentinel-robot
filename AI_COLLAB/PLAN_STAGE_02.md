**对阶段 2 的影响（重要）**：

1. **简化**：IMU 自带卡尔曼融合并直接输出 yaw，我们**不必自己写姿态解算 / 零漂标定 / EKF**。原本 S2-04 里「静止陀螺零漂标定、安装方向标定」部分可由模块提供（或上位机配置），STM32 侧只需**读取 yaw 角与 yaw_rate**。
2. **⚠️ 坐标系冲突（必须解决）**：官方说明「九轴算法下 Z 轴角度是**绝对角**，东北天坐标系，0° 时 Y 轴指北，**不能相对归零**」。而我们的约定是**车体相对 yaw、+Z 逆时针、可归零**。
   - 处理方案（WorkBuddy 定）：`IMU_GetYaw()` 返回**相对角** —— 上电记录初始 `yaw0`，运行时 `yaw_rel = wrap(imuRawYaw − yaw0)`；方向按安装方向标定，保证逆时针为正。融合时用相对角，不用绝对北向。
   - 若用 6 轴版本（无磁力计），yaw 可能无绝对参考，按角速度积分 + 编码器纠正。
3. **接口选 UART 还是 I2C 待定**：I2C 可与 OLED 共用 PB6/PB7（地址需确认不冲突）；UART 需占用一个 USART（建议 USART1/USART6，避开调试口）。**接线前必须走架构变更报备，由 Codex 改 `.ioc`**，实现模型不得自行改 CubeMX。

**适用性评估（WorkBuddy 11-20 18:59）**：模块本身适合本项目 —— 自带解算直出 yaw、精度远超验收线，能省掉自写姿态融合。但用法要保守：

1. **波特率必须改**：默认 9600 bps 不够。100~200 Hz 输出一帧十几到二十几字节，100 Hz 就需 12~20 kbps，9600 会丢帧/降频。**S2-04 一律配 115200 bps**（模块支持 4800~921600），上位机与 STM32 两侧都要改。
2. **优先用 6 轴模式（仅陀螺仪 yaw_rate + 编码器纠正），先不启用磁力计**：轮径仅 66 mm，电机就在旁边，强电流磁场会干扰磁力计导致 9 轴 yaw 跳变（亚博官方也提示 yaw 抖动需磁力校准）。我们的需求是相对 yaw、不做绝对航向，6 轴够用且避开干扰。若 6 轴漂移压不住，再现场磁力校准后试 9 轴，但接受电机干扰风险。
3. **安装**：远离电机与电源线，Z 轴朝上固定牢。

> **不用开中断（查证 11-21 14:38，超时 14:40 收紧）**：维特 I2C 读是纯主机轮询（`WitReadReg()` → `IICreadBytes()` 标准 I2C 时序），模块无 DRDY/数据就绪中断引脚。CubeMX 不给 IMU 开 EXTI/I2C 中断；在 1 ms 控制环里做 10 ms 分频轮询读（匹配 100 Hz 输出），`HAL_I2C_Mem_Read` 超时 **2 ms**（异常时最多卡 2 个 PID 周期）。若实测扰动 PID 再升级 TIM6/I2C IT，由人类裁决。

## 七、WorkBuddy 拍板的实现细则（6 条）

> 用户 2026-11-20 17:04 裁定：这些细则由 WorkBuddy 定；Codex 只做规划；IMU 选型/引脚等到 S2-04 前再单独立项。

### 细则 1 — track_width 不猜数值，用可写变量 + 两级标定

- S2-01 定义 `float chassisTrackWidthM = 0.0f;`（Watch 可写，单位 m）。**未标定时为 0**。
- 安全逻辑：`chassisTrackWidthM <= 0` 时 `Chassis_SetVelocity()` 只接受 omega=0 的直行指令，带 omega 的指令拒绝执行并回报错误 —— 防止用错误轮距跑出错误姿态。
- **几何轮距已实测（人类 11-20 20:59）**：左右轮中心距约 **0.20 m（20 cm，粗测）**，作为初值填入 `chassisTrackWidthM`；用户明确「后期测试再校准」。WorkBuddy 验算：0.20 m 对应理论 omega 上限 `2×0.869/0.20 = 8.69 rad/s`，而 S2-01 代码当前写死 6.0 rad/s（按旧粗估 0.29 m 算的）——**偏保守但安全**，S2-02 按实测轮距重算并注明。
- **⚠️ S2-03 实车证实等效轮距约 0.40 m（11-21 14:21）**：原地转 90°（按几何 0.20 m 积分到 +90° 停）实际仅转约 45° → 等效滑移轮距约 **0.40 m ≈ 几何 2 倍**。skid-steer 原地旋转横向打滑严重，单靠几何轮距积分 yaw 误差大；直行距离则较准（1 m 实测 1.03 m，+3%）。**结论**：S2-04 用 IMU 解决打滑航向精度；S2-05 必须标定等效轮距（预计约 0.40 m）而非直接用几何值。
- **等效轮距**：skid-steer 转弯有侧滑，几何轮距与运动学等效轮距不同。S2-05 原地旋转 360°，用四轮累计距离反推：`track = (右轮累计距离 − 左轮累计距离) / π`，取 M1/M3 为左侧、M2/M4 为右侧，左右各求平均后填入 `chassisTrackWidthM`。
- 派单里**不许直接写死一个猜的轮距数值**。

### 细则 2 — IMU 硬件到 S2-04 前单独立项

- S2-01~S2-03 **不接 IMU 硬件**：`IMU_GetYaw()` / `IMU_GetYawRate()` 只留函数空位，返回 0 或明确标记不可用，上位机/里程计不得依赖其有效值。
- S2-04 开工前置：人类确认型号 / 接口 / 供电 / 引脚 / 轴向 / 安装方向 → 报架构变更 → Codex 改 `.ioc` → 才允许接线。实现模型不得自行改 CubeMX。
- 用户已明确：IMU 选型引脚到需要时再规划。

### 细则 3 — motor_gain / wheel_scale 在 S2-01 就预留

- S2-01 定义 `float motorGain[MOTOR_COUNT]` 和 `float wheelScale[MOTOR_COUNT]`，**默认均 1.0f**，Watch 可写。
- S2-02 输出目标 RPM 前乘 `motorGain[i]`，补偿后再限幅 ±250 RPM。
- S2-03 里程计用 `Encoder_GetDistanceM(i) * wheelScale[i]`。
- 两者独立，不合并；**不许改 `WHEEL_DIAMETER_M` 掩盖电机差异**。S2-05 只标定这两个数组。

### 细则 4 — 接口形式定死

```c
void Chassis_SetVelocity(float vx, float omega);              /* m/s, rad/s */
void Chassis_Update(float dt);                                /* 挂 1 ms SysTick，dt = CONTROL_PID_DT */
void Chassis_GetPose(float *x, float *y, float *yaw);         /* 指针出参，不用返回值 */
float IMU_GetYaw(void);                                       /* rad，S2-04 前返回 0 */
float IMU_GetYawRate(void);                                   /* rad/s，S2-04 前返回 0 */
```

- 轮序：M1 左前、M2 右前、M3 左后、M4 右后（`main.h` 引脚命名 zuoqian/youqian/zuohou/youhou）。**左 = M1/M3，右 = M2/M4**。
- omega 正向（+Z 逆时针）→ 左轮减速、右轮加速，与规划公式一致。
- 线速度 → RPM：`rpm = v_mps * 60.0f / (3.14159265f * 0.066404f)` ≈ `v_mps * 287.6`。派单必须写明，不许实现模型自己推。

### 细则 5 — 通信（已移出阶段 2，参考口径存档）

- **人类 11-21 裁定：基础电脑通信不属于阶段 2，阶段归属留空待阶段末规划**。以下口径仅为届时参考，不是阶段 2 任务。
- 参考口径：基础 = UART 定长帧 + 序号 + 校验 + 两模式指令 + 遥测 + 超时停车；完整 = 变长帧 / CRC16 / 心跳 / 重连 / 发射互锁。
- **通信超时建议 200 ms**：超过 200 ms 未收到有效帧 → 四轮目标归零停车。派单里不许写「约定时间」这种模糊表述。

### 细则 6 — ±250 RPM 饱和用等比缩放

- 先算左右轮目标速度，若任一超过 ±250 RPM，取 `k = 250 / max(|left|, |right|)`，**左右同乘 k** 整体等比缩放，保持 vx:omega 比例 —— 单侧独立截断会破坏差速关系、导致 yaw 漂移。
- 缩放后再乘 `motorGain[i]`，再限幅一次 ±250 RPM。
- vx 自身上限：`250 / 287.6 ≈ 0.869 m/s`，作为 `Chassis_SetVelocity()` 输入校验。
