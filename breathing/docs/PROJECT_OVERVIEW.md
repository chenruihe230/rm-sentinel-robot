## 2. 总体架构

```text
摄像头 / 激光雷达 / GPS（远期）
              ↓
Raspberry Pi 5 / 上位机
  视觉、展示、导航、任务决策
              ↓
HC-12 / UART / 后续高速链路
              ↓
STM32F407
  四轮 PID、运动学、IMU、云台、发射、安全
              ↓
电机 / 编码器 / IMU / 云台 / 发射机构
```

模块边界：

- STM32 负责实时控制、执行器保护和安全停车。
- 树莓派/上位机负责展示、视觉、任务和高层指令。
- HC-12 当前用于基础无线遥测和控制，不承担未来发射安全互锁。
- `S3-DEMO` 展示层是独立可演进模块，不反向约束 STM32 固件架构。

HC-12 基础通信：

```text
半双工：电脑请求 → STM32 响应
定长帧：AA55 | TYPE | SEQ | DATA | CRC8 | 0D0A
```

## 7. 工程结论

1. HC-12 是半双工，必须主从轮询；低波特率换取更远距离，当前选择 9600。
2. 超时阈值必须匹配链路 RTT。无线 RTT 为 122～180 ms，因此采用 400 ms。
3. USART1 中断优先级高于 SysTick，但回调足够短时不会影响 1 ms 控制。
4. IMU 融合解决 skid-steer 原地旋转打滑，360° 偏差降至约 +0.18°。
5. 等效轮距 0.3703 m 与几何轮距差异显著，运动学必须使用实测等效值。
6. 无线遥测 5.6～7.1 Hz 是 HC-12 物理限制，不作为实现缺陷。
7. `chassis.c` 中 200 ms 超时注释已过时，实际为 400 ms，后续触及该文件时修正。

## 8. 遗留项处置

| 遗留项 | 处置 |
|---|---|
| 无线遥测仅 5.6～7.1 Hz | 接受为基础链路物理限制；未来需要 20 Hz 时换 2.4G 或有线高速链路 |
| 单轮 1 m M1/M3 为 2.01% | 接受为压线记录；严格卡 2% 时用更高精度量具复测 |
| `chassis.c:442` 注释仍写 200 ms | 后续触及该文件时修正，不阻塞当前阶段 |
| S3-DEMO v3 停止误差为 Mock | 保持仿真标注；可选实车验证后封板 |
| 高精度定点/停止 | 独立规划「小车闭环升级版」，不混入阶段 4 云台任务 |

## 11. 协作规则

1. 同一个文件同一时间只能有一个模型修改。
2. 免费工具优先完成调研、文档、测试和初审。
3. 付费模型只做关键架构、疑难排错和阶段验收。
4. 每个开发任务必须限定修改文件范围。
5. CubeMX、定时器、引脚和安全逻辑不得由实现模型随意修改。
6. 每个阶段完成后必须编译、测试、记录，再进入下一阶段。
7. 实车测试结果由人类确认，仿真数据不得替代实车结论。

## 12. 安全底线

```text
硬件急停优先级最高
上电默认停车
通信超时 400 ms 必须强制停车
强制停车必须退出航向/动作模式并清零四轮目标
PWM 和积分必须限幅
目标轮速限制 ±250 RPM
PID 循环禁止 HAL_Delay
发射必须有独立互锁
目标丢失必须禁止发射
```
